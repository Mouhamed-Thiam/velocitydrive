# 🚗 VelocityDrive – Plateforme de Vente de Voitures

**VelocityDrive** est une application web moderne dédiée à la vente et à l’achat de véhicules en ligne. Ce projet vise à offrir une expérience utilisateur fluide, rapide et intuitive pour parcourir, comparer et acquérir des voitures en quelques clics.

## 🔥 Objectifs du projet

* Simplifier le processus d’achat et de vente de voitures
* Offrir une interface claire et responsive (desktop & mobile)
* Mettre en avant les véhicules avec des fiches détaillées et visuelles
* Permettre une navigation rapide et efficace entre les annonces

## 🛠️ Technologies utilisées

* **HTML5** – Structure du site
* **CSS3 / Bootstrap** – Design responsive et moderne
* **JavaScript (Vanilla / JS Framework si utilisé)** – Interactivité dynamique
* **EmailJS** - Gérer la communication entre les utilisateurs et les vendeurs, VelocityDrive utilise EmailJS
* **(Optionnel)** Backend (Node.js / PHP / Firebase / etc.)

## ⚙️ Fonctionnalités principales

* 🔍 Recherche et filtrage des véhicules (prix, marque, modèle, etc.)
* 📄 Fiches détaillées pour chaque voiture
* 🖼️ Galerie d’images pour chaque véhicule
* ❤️ Système de favoris (optionnel)
* 📞 Formulaire de contact ou demande d’information
* 🔐 Authentification utilisateur (si implémentée)

## 🚀 Installation & Utilisation

1. Cloner le repository :

```bash
git clone https://github.com/Mouhamed-Thiam/velocitydrive.git
```

2. Ouvrir le fichier `index.html` dans un navigateur
   ou lancer via un serveur local (Live Server recommandé)
